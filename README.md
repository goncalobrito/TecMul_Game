Chroma Escape é um jogo de puzzle e exploração em primeira pessoa onde a cor não é apenas estética — é a chave para a tua sobrevivência e progresso. Manipula o ambiente, interage com as tonalidades ao teu redor e descobre o caminho para o portal final.

-- Sobre o Jogo

```
 Preso num complexo labiríntico de salas monocromáticas e vibrantes, o teu objetivo é simples: escapar.
 No entanto, o caminho está bloqueado por mecanismos que reagem apenas a frequências de cores específicas.
 Usa a lógica e a tua percepção visual para desvendar os segredos de cada sala.
```
Destaque Especial:
```text
   o- Mecânica de Cores: O cenário é vivo. Interage com objetos coloridos para abrir portas, ativar pontes ou revelar segredos.
   o- Atmosfera Imersiva: Usa a tua lanterna para explorar cantos escuros e... bem, tens uma caçadeira.
        Ela não dispara balas, mas o estrondo pode ser útil (ou apenas satisfatório).
```
Comandos

Prepara-te para a fuga com os seguintes controlos:

```text
Tecla                  /                  Ação
#--------------------------------------------#
W, A, S, D          Movimentação do Personagem
SHIFT                                   Correr
ESPAÇO                                  Saltar
CTRL                                   Agachar
E              Interagir com o Cenário / Cores
F                      Ligar/Desligar Lanterna
RATO ESQUERDO               Disparar Caçadeira
```

Como Jogar

    o- Explora: Cada sala tem um puzzle único baseado em cores.
    o- Interage: Usa a tecla [E] em objetos que pareçam reagir à luz ou cor.
    o- Resolve: Alinha as cores corretas para desbloquear o acesso à próxima área.
    o- O Portal: O teu objetivo final é o portal luminoso. Alcança-o para vencer o desafio.


Instalação

    Faz o download do repositório.
    Entrar pasta BUILDE.
    Executa o ficheiro TP1.exe.
    Sobrevive.
